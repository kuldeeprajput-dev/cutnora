# Editor text fonts

Self-hosted Latin subsets from [Google Fonts](https://fonts.google.com/), downloaded
through its CSS API. Font files are served locally; the editor makes no requests
to Google Fonts at runtime. Characters outside these subsets use the font stack's
system fallback.

Families: Inter, Montserrat, Anton, Oswald, Playfair Display, Dancing Script,
Great Vibes, Pacifico, and Space Mono. Each family's SIL Open Font License is
included in its `*-OFL.txt` file, sourced from
[google/fonts](https://github.com/google/fonts/tree/main/ofl).
